# Learning Log

A running log of my self-taught journey through computer science — lessons, notes, half-formed thoughts, and the occasional "wait, that finally makes sense" moment.

This isn't polished documentation. It's closer to a notebook: written as I go, right after each lesson, while it's still fresh. Expect rough edges.

## Why this exists

I'm exploring several branches of CS before committing to one path — web development, cybersecurity, and whatever else catches my interest along the way. This log is where I track that exploration as it happens, rather than trying to reconstruct it later.

Eventually, a lot of this will feed into a portfolio site I'm building — a kind of skill-tree-based site that maps out what I've learned and what I'm working toward next. This repo is the raw material for that.

## Structure

Each path gets its own folder. Inside, entries are dated and roughly correspond to a lesson or work session.

Example:
learning-log/
odin/ → The Odin Project
mooc/ → MOOC coursework
google-cert/ → Google certification
cybersec/ → TryHackMe / cybersecurity study

## Entry format

Nothing fancy — usually just:

```markdown
# [Topic] — [Date]

## What I did
## What clicked
## What confused me
## Random thoughts
```
